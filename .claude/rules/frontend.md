# Frontend

- Komponent odpowiada za jeden element doświadczenia.
- Treści użytkowe trzymamy w `app/content/site.ts`.
- Każda interakcja musi działać kursorem, klawiaturą i dotykiem.
- Animacje respektują `prefers-reduced-motion`.
- Nie dodawaj ciężkiej biblioteki ruchu bez udokumentowanej potrzeby.
